Frame the problem before touching the data

A margin problem breaks down into a small number of drivers. The KPI tree sets what to measure; the hypotheses set what to test.

KPI tree, per tonne sold, FY2024 → FY2025
Hypotheses tested
  • ~"Prices fell because the market fell."
    Partly true. Indexed contracts actually rose; the erosion is concentrated in fixed annual contracts.
  • ✓"Costs rose because of fibre, energy and FX."
    Mostly true, with one exception: an energy drift at one plant is internal and fixable.
  • ✕"Volume growth is good growth."
    Not entirely. Part of the growth came from small accounts whose cost-to-serve exceeds their margin.

-- Customer-level EBITDA bridge (excerpt of sql/03_ebitda_bridge.sql)
cy AS (   -- FY2024 and FY2025 side by side, constant currency
  SELECT a.customer_id,
         a.vol AS v24, b.vol AS v25,
         a.sales_cc / a.vol AS p24,  b.sales_cc / b.vol AS p25,
         a.fibre / a.vol    AS fib24, b.fibre / b.vol    AS fib25,
         (a.sales_cc - a.fibre - a.energy_cc - a.other_var - a.cts_cc)
           / a.vol AS ucm24                 -- unit contribution FY2024
  FROM cust_year a
  JOIN cust_year b ON b.customer_id = a.customer_id
                  AND a.year = 2024 AND b.year = 2025
)
SELECT 'Volume', (tot.v25 - tot.v24) * tot.ucm24_avg FROM tot
UNION ALL SELECT 'Mix',   SUM(v25 * ucm24) - tot.v25 * tot.ucm24_avg ...
UNION ALL SELECT 'Price', SUM(v25 * (p25 - p24)) FROM cy
UNION ALL SELECT 'Fibre cost', -SUM(v25 * (fib25 - fib24)) FROM cy
...
# Weekly energy anomaly rule (excerpt of python/02_analysis.py)
e["intensity"] = e.energy_mwh / e.production_t
base = (e[e.yr == 2024].groupby(["plant_id", "woy"]).intensity.mean()
        .groupby(level=0)
        .transform(lambda s: s.rolling(5, center=True, min_periods=1).mean()))
e = e.merge(base.rename("baseline").reset_index(), on=["plant_id", "woy"])
e["dev"] = e.intensity / e.baseline - 1
e["dev_4w"] = e.groupby("plant_id").dev.transform(
    lambda s: s.rolling(4, min_periods=4).mean())

# Alert: 4-week deviation above +6% for three weeks in a row
e["breach"] = e.dev_4w > 0.06
e["run"] = e.groupby("plant_id").breach.transform(
    lambda s: s.groupby((~s).cumsum()).cumcount())
alerts = e[(e.run >= 3) & (e.yr == 2025)].groupby("plant_id").week_start.min()
-- Power BI measures (excerpt of powerbi/measures.dax)
EBITDA =
    [Net Sales] - [Fibre Cost] - [Energy Cost] - [Other Variable Cost]
  - [Cost to Serve] - [Fixed Cost]

EBITDA Margin % = DIVIDE ( [EBITDA], [Net Sales] )

Cost to Serve per t = DIVIDE ( [Cost to Serve], [Volume t] )

Price Effect CC =        -- variables inside SUMX: evaluated per customer
SUMX (
    VALUES ( dim_customer[customer_id] ),
    VAR V25 = CALCULATE ( [Volume t], dim_date[year] = 2025 )
    VAR V24 = CALCULATE ( [Volume t], dim_date[year] = 2024 )
    VAR P25 = DIVIDE ( CALCULATE ( [Net Sales CC], dim_date[year] = 2025 ), V25 )
    VAR P24 = DIVIDE ( CALCULATE ( [Net Sales CC], dim_date[year] = 2024 ), V24 )
    RETURN V25 * ( P25 - P24 )

Put AI and automation where they pay back

Not every idea is worth building. Each initiative is sized from the data, scored for effort, and given a confidence level before anyone writes code.

Value vs effort

Value is full-year EBITDA impact, EUR m. Effort: 1 = weeks with existing data, 5 = new systems and a pilot.

Where AI fits, and where it does not

Rules first. The energy alert is a simple statistical rule. It is cheap, explainable and caught the problem.

Machine learning where patterns are complex. Demand sensing for planning has real value but low confidence until a pilot proves it.

Generative AI for language work, with controls. Drafting variance commentary is repetitive; checking the numbers must stay automatic and the sign-off human.

AI agent: month-end variance commentary
1 · FactsPulls verified figures from the single source of truth only.
2 · DraftAn LLM writes the commentary under strict rules: no new numbers, market vs controllable.
3 · CheckEvery number in the draft is traced back to the facts. Untraceable numbers are flagged.
4 · ReviewA controller edits and signs off. The agent never publishes on its own.

Prove the value was delivered

An initiative is not done when it launches; it is done when the KPI moves and the EBITDA shows up. Each one gets a baseline, a target, an owner and a review rhythm.

Leading indicators show within weeks whether an initiative is on track; lagging indicators confirm the financial result. Both are reviewed in the monthly business review.
